# Receipts.dev

**Prove your skills with code, not buzzwords.**

Receipts.dev turns your real Git history into evidence-linked "skill receipts" - every claimed skill deep-links to the exact diff you wrote, and lets recruiters interrogate your actual code with an AI that can only cite your real commits.

---

## The Problem

In 2026, AI-generated resumes have made skill claims impossible to trust. 65% of hiring managers say they can't verify whether a candidate actually wrote the code they claim. Receipts.dev fixes this at the source: your Git history is already the evidence.

## How It Works

1. **Connect GitHub** - OAuth login, zero manual input
2. **Index your repos** - background pipeline extracts skills from every diff you've ever written, embedding each code chunk with its commit context
3. **Share your profile** - `receipts.dev/yourname` is a public, SEO-optimized page showing your verified skill graph
4. **Recruiters can ask your code** - an AI chat on your profile page answers questions about your skills, but can only cite actual commits you wrote

## Quick Start

### Prerequisites
- Docker and Docker Compose
- GitHub OAuth App ([create one here](https://github.com/settings/developers))
- OpenAI API key

### Setup

```bash
# Clone and enter the project
git clone https://github.com/yourusername/receipts-dev
cd receipts-dev

# Configure environment
cp api/.env.example api/.env
# Edit api/.env - fill in:
#   GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET
#   OPENAI_API_KEY
#   SECRET_KEY (generate: openssl rand -hex 32)

# Start everything
docker compose up --build
```

- Frontend: http://localhost:3000
- API + docs: http://localhost:8000/docs

### Local Development (without Docker)

```bash
# Backend
cd api
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --port 8000

# Celery worker (second terminal)
cd api
celery -A app.workers.celery_app worker --loglevel=info --concurrency=2

# Frontend (third terminal)
cd web
npm install
npm run dev
```

## Architecture

```
Browser
  ├── Next.js 15 frontend (port 3000)
  │     ├── SSR profile pages (ISR revalidate=3600)
  │     ├── Recruiter chat with streaming citations
  │     └── Dashboard: repo picker + indexing progress
  └── FastAPI backend (port 8000)
        ├── GitHub OAuth + httpOnly JWT
        ├── Repository indexing API
        ├── Public profile + skills API
        └── Recruiter chat API
              └── Celery workers
                    ├── GitHub API: fetch commits + diffs
                    ├── Chunker: split diffs into semantic chunks
                    ├── OpenAI: embed chunks (text-embedding-3-small)
                    ├── LLM extractor: identify skills per chunk
                    └── pgvector: store + index embeddings
```

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `GITHUB_CLIENT_ID` | Yes | GitHub OAuth App client ID |
| `GITHUB_CLIENT_SECRET` | Yes | GitHub OAuth App client secret |
| `OPENAI_API_KEY` | Yes | OpenAI API key (embeddings + GPT-4o) |
| `SECRET_KEY` | Yes | 64-char hex string for JWT signing + token encryption |
| `DATABASE_URL` | Yes | PostgreSQL connection URL (asyncpg) |
| `REDIS_URL` | Yes | Redis connection URL |
| `FRONTEND_URL` | Yes | Base URL of the Next.js frontend |
| `GITHUB_CALLBACK_URL` | Yes | OAuth callback URL (backend) |
| `INTERNAL_API_URL` | Docker only | `http://api:8000` - for SSR fetches inside Docker |

## CI/CD
