| `ANTHROPIC_API_KEY` | YES | Claude API key — must be set before calling `pinpoint scan` |
| `GITHUB_TOKEN` | no | GitHub PAT — raises changelog fetch rate limit from 60 to 5000 req/hr |

from any `.pinpoint.json` that happens to contain it.

## Decisions made explicit from the contract

### Installed version discovery
The contract specifies `get_dependency_info(package, ecosystem, installed)` with
`installed` as a caller-supplied parameter.  The pipeline resolves the installed
version by calling `fetcher.base.get_installed_version(package, ecosystem, root)`
before invoking `get_dependency_info`.  Lookup order:

- **npm**: `package-lock.json` (lockfile v2 `packages` then v1 `dependencies`),
  then `package.json` (strips `^~/>=<` prefix).
- **pypi**: `requirements.txt` (only `==` pins), then `pyproject.toml`
  (searches for `==` in dependency strings).
- Fallback: `"0.0.0"` — package is still processed and compared against PyPI/npm.

### Ecosystem detection
`ImportMap` has no `ecosystem` field (per contract).  The pipeline infers it from
`call_sites[].file` extensions: `.py` → `"pypi"`, anything else → `"npm"`.

### OSV ecosystem casing
OSV.dev requires `"PyPI"` (capital P, capital I) for Python packages; the internal
string is `"pypi"` everywhere else.  `cve/osv.py` maps `"pypi" → "PyPI"` at the
boundary.

### Non-fatal error policy
`FetchError` for a package → skip that package (stdlib / private registry hits).
`CVEFetchError` → continue with empty CVE list.
`LLMError` → emit a safe-default `ClaudeVerdict` (risk `"none"`) so the scan
always completes rather than aborting mid-run.

### cli.py and report.py
These are listed as frontend tasks in the architecture but are required for the
package entry point to exist.  Full implementations are provided so the smoke test
passes and the frontend agent can iterate on top of them.

### tree-sitter version
Pinned to `0.21.x` range.  The 0.21 API changed to `Language(grammar.language())`
(no more `.build_library`); `tree-sitter-typescript 0.21` exposes
`language_typescript()` and `language_tsx()` as separate functions.
