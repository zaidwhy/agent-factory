## Bugs Fixed

### CRITICAL

**`output/api/app/dependencies.py:21-37`** - Auth completely broken.
- Symptom: Every protected endpoint returned 401 immediately after OAuth login.
- Root cause: httpOnly cookies are invisible to `document.cookie`; `getCookie("receipts_token")` in `api.ts` always returned null; Authorization header was never set.
- Fix: Added `receipts_token: str | None = Cookie(default=None)` parameter to `_get_bearer_token`; falls back to the cookie when Authorization header is absent.

### HIGH

**`output/api/app/routers/profiles.py:122-246`** - N+1 queries in `get_profile_skills`.
- Fix: Replaced with a single CTE using `ROW_NUMBER() OVER (PARTITION BY skill_evidence_id ORDER BY relevance_score DESC)`. All skills and their top-3 evidence arrive in one query.

**`output/api/app/workers/index_tasks.py:219-231`** - N+1 SHA-existence check.
- Fix: Single `SELECT sha FROM commits WHERE repo_id = ?` fetches all existing SHAs into a Python `set`; membership test is O(1).

**`output/api/app/workers/index_tasks.py:143-215`** - `is_indexed=True` even when every repo failed.
- Fix: Track `repos_indexed` counter. Only mark `is_indexed = true` when at least one repo succeeded; otherwise set job status to `failed`.

**`output/api/app/routers/index.py:59-80`** + **`output/api/alembic/versions/0002_add_unique_active_job_index.py`** - Race condition on job creation.
- Fix: New migration adds `CREATE UNIQUE INDEX uq_one_active_index_job_per_user ON index_jobs (user_id) WHERE status IN ('queued', 'running')`. Router catches `IntegrityError` and returns 409.

**`output/docker-compose.yml:88-101`** - `web` service missing.
- Fix: Added `web` service using `./web/Dockerfile`, exposed on port 3000, depends on `api`.

### MEDIUM

**`output/api/app/routers/chat.py:154-173`** - Rate-limit TOCTOU.
- Fix: `INCR` first, set TTL only on `new_count == 1`, then check limit. Increment is atomic in Redis.

**`output/api/app/routers/chat.py:175-187`** - `session.message_count` persistence on error.
- Fix: Moved increment to before the user-message commit so both persist atomically.

**`output/api/app/routers/auth.py:95-123`** - OAuth denial caused FastAPI 422.
- Fix: Made `code`, `state` optional; added `error: str | None` param; graceful redirect to frontend with error code.

**`output/api/app/services/retriever.py:32-62`** - Cosine distance computed twice.
- Fix: CTE computes distance once as column alias; outer query reads precomputed value for both filtering and projection.

**`output/api/app/routers/repositories.py:38-112`** - Redis connection leak.
- Fix: Single top-level `try/finally: await r.aclose()` wraps the entire function body.

**`output/web/src/lib/api.ts:47-55`** - Stale auth state on 401.
- Fix: On 401, dynamically import `useAuthStore` and call `clearAuth()`.

**`output/web/src/components/profile/IndexingPollerClient.tsx`** - Dead polling path and misleading comment.
- Fix: Added `refetchInterval: data?.is_indexed ? false : 10_000` to query; removed unconditional 30-second refresh.

**`output/api/alembic/versions/0003_add_zero_vector_count.py`** - Zero-vector count not surfaced.
- Fix: Added `zero_vector_count INTEGER NOT NULL DEFAULT 0` to `index_jobs`. Task accumulates count and persists it. `IndexJobOut` includes `zero_vector_count`.

### LOW

**`output/api/app/routers/auth.py:79-92`** - OAuth redirect_uri not percent-encoded.
- Fix: Use `urllib.parse.urlencode()` for the full parameter dict.

**`output/web/src/types/index.ts:87-93`** - TypeScript type mismatch: `confidence` typed as `number` not `number | null`.
- Fix: Changed to `number | null`.

**`output/web/src/app/auth/callback/page.tsx`** - OAuth denial UX showed generic message.
- Fix: Read `?status=error` query param and show specific human-friendly message per error code.

## Performance Findings

- **[HIGH] N+1 in `get_profile_skills`** - FIXED: single CTE with window function; O(N) -> O(1) DB round-trips
- **[HIGH] N+1 SHA check in `_index_repo`** - FIXED: one bulk SELECT + Python set; O(M) per repo -> O(1)
- **[MEDIUM] Double cosine distance computation** - FIXED: CTE materializes distance once per candidate row
- **[LOW] Redis pool per request** - NOT FIXED: at MVP scale this is negligible; fix at 100+ req/s with module-level singleton

## Security Findings

- **[CRITICAL] Auth cookie never read by backend** - FIXED
- **[HIGH] Race condition on index job creation** - FIXED: partial unique DB index + IntegrityError catch
- **[MEDIUM] Rate-limit TOCTOU** - FIXED: INCR-first pattern
- **[MEDIUM] OAuth denial unhandled (FastAPI 422 exposed)** - FIXED: graceful redirect with error code

## Remaining Risks / Follow-ups

1. **Docker SSR API calls**: `NEXT_PUBLIC_API_URL=http://localhost:8000` works for browser clients but Next.js SSR fetches inside Docker fail because `localhost:8000` is the container itself. Fix: add `INTERNAL_API_URL=http://api:8000` env var for server-side fetches.

2. **Redis connection pool per request**: `aioredis.from_url()` called per-request creates a new pool. Replace with a module-level singleton or `app.state` pool managed in the FastAPI lifespan.

3. **No Content-Security-Policy**: Add a restrictive CSP in `next.config.ts` to reduce XSS risk.

4. **Stale Celery jobs**: If the worker process crashes mid-indexing, `index_jobs` rows stay in `running` state forever. Add a periodic Celery beat task to transition stale running jobs to `failed` after a configurable timeout.

5. **OpenAI API key read at module load time**: Key rotation requires a full process restart. Low risk for MVP.
