# Architecture: PinPoint

> **Note on stack deviation:** The idea explicitly specifies a Python CLI — no web server, no browser frontend. The standard FastAPI + React default does not apply. "Backend" below means core scanning/fetching/LLM logic; "Frontend" means the CLI interface and Rich report layer. Both can be built in parallel once `output/pinpoint/models.py` is written first.

---

## Stack

- **Runtime:** Python 3.11+ — `ast` stdlib covers Python scanning; tree-sitter bindings cover JS/TS; ships as a `pipx`-installable single command
- **CLI framework:** Typer — declarative, type-annotated CLI with auto-generated help; simpler than Click for this scope
- **AST parsing:** `tree-sitter` (Python binding) + `tree-sitter-javascript` + `tree-sitter-typescript` grammars — accurate import/call-site extraction without regex fragility; Python scanning uses stdlib `ast` (no extra dep)
- **HTTP client:** `httpx` (sync) — used by all fetcher modules (npm registry, PyPI JSON API, OSV.dev, GitHub releases); one shared client instance
- **LLM:** Anthropic Python SDK (`anthropic`) targeting `claude-sonnet-4-5` — tool_use for structured JSON verdicts; one call per outdated dependency
- **Data validation:** Pydantic v2 — all internal data models, config schema, and Claude response parsing
- **Terminal output:** Rich — colored verdict table, progress spinners, risk-level badges
- **Packaging:** `pyproject.toml` (hatchling build backend) — `pipx install pinpoint` installs the `pinpoint` command globally

## Data model

All models live in `output/pinpoint/models.py`. These are the canonical shapes shared by every module.

```
Config
  language:        str                   # "python" | "javascript" | "typescript" | "auto"
  include_paths:   list[str]             # glob patterns, default ["**/*.py","**/*.ts","**/*.js"]
  exclude_paths:   list[str]             # default ["node_modules","__pycache__",".venv","dist"]
  model:           str                   # default "claude-sonnet-4-5"
  anthropic_key:   str | None            # falls back to ANTHROPIC_API_KEY env var
  max_concurrent:  int                   # default 5, caps parallel dependency lookups

ImportMap
  package:         str                   # package name as it appears in lock file
  identifiers:     list[str]             # every named symbol the project calls from this package
                                         # e.g. ["debounce", "throttle"] for lodash
  call_sites:      list[CallSite]        # source locations for traceability

CallSite
  file:            str                   # relative path from project root
  line:            int
  identifier:      str

DependencyInfo
  package:         str
  ecosystem:       str                   # "npm" | "pypi"
  installed:       str                   # semver string e.g. "4.17.20"
  latest:          str                   # semver string e.g. "4.17.21"
  changelog_text:  str                   # raw changelog/release-notes for the version range

CVERecord
  cve_id:          str                   # e.g. "CVE-2021-23337"
  severity:        str                   # "CRITICAL" | "HIGH" | "MEDIUM" | "LOW" | "UNKNOWN"
  description:     str
  affected_versions: list[str]           # version ranges from OSV
  vulnerable_functions: list[str]        # extracted from OSV details; may be empty list

ClaudeVerdict
  risk_level:               str          # "none" | "low" | "medium" | "high"
  relevant_changelog_lines: list[str]    # changelog entries that touch the user's identifiers
  affected_identifiers:     list[str]    # subset of ImportMap.identifiers that are touched
  safe_identifiers:         list[str]    # subset confirmed safe
  cve_affects_you:          bool
  cve_reason:               str          # one-sentence explanation
  summary:                  str          # human-readable one-liner verdict

FinalVerdict
  package:          str
  installed:        str
  latest:           str
  identifiers_used: list[str]            # from ImportMap
  risk_level:       str                  # from ClaudeVerdict
  relevant_changes: list[str]
  cve_records:      list[CVERecord]
  cve_affects_you:  bool
  summary:          str
```

## API contract  (SOURCE OF TRUTH — engineers must not deviate)

Since PinPoint is a CLI tool, the contract covers four surfaces: (1) CLI commands, (2) config file schema, (3) internal module interfaces (the boundaries between backend and CLI layers), and (4) external API consumption shapes.

---

### 1. CLI commands

```
pinpoint scan [PROJECT_DIR]
  --config PATH          path to .pinpoint.json (default: PROJECT_DIR/.pinpoint.json)
  --output [table|json]  output format (default: table)
  --min-risk [none|low|medium|high]  only show verdicts at or above this level (default: low)
  --verbose              show raw changelog text and call sites
  --quiet                only print verdicts with risk >= medium, no spinners
  --no-color             disable Rich color output

pinpoint init [PROJECT_DIR]
  Writes a default .pinpoint.json to PROJECT_DIR and exits.
  No flags.

Exit codes:
  0  scan completed, no high-risk findings
  1  scan completed, at least one high-risk finding found
  2  configuration error or missing API key
  3  network/API error
```

---

### 2. Config file schema (.pinpoint.json)

```json
{
  "language":        "auto",
  "include_paths":   ["**/*.py", "**/*.ts", "**/*.tsx", "**/*.js", "**/*.jsx"],
  "exclude_paths":   ["node_modules", "__pycache__", ".venv", "dist", "build"],
  "model":           "claude-sonnet-4-5",
  "max_concurrent":  5
}
```

All fields optional; defaults shown above. `anthropic_key` is NOT stored in config — must come from `ANTHROPIC_API_KEY` env var.

### 3. Internal module interfaces

These are the function signatures the CLI layer calls into (the "backend API"). They must not change without updating both sides.

#### `scanner.scan_project(root: Path, config: Config) -> dict[str, ImportMap]`
- Returns mapping of package name to ImportMap for every import found in the project.
- Raises `ScanError` on parse failure.

#### `fetcher.get_dependency_info(package: str, ecosystem: str, installed: str) -> DependencyInfo`
- Fetches changelog text for the version range `installed..latest`.
- Returns `DependencyInfo` with `latest == installed` and empty `changelog_text` if already up to date.
- Raises `FetchError` on network failure.

#### `cve.get_cves(package: str, ecosystem: str, version: str) -> list[CVERecord]`
- Queries OSV.dev for CVEs affecting `version`.
- Returns empty list if no CVEs.
- Raises `CVEFetchError` on network failure.

#### `llm.get_verdict(import_map: ImportMap, dep: DependencyInfo, cves: list[CVERecord], config: Config) -> ClaudeVerdict`
- Sends one Claude API call using tool_use.
- Returns structured `ClaudeVerdict`.
- Raises `LLMError` on API failure.

#### `pipeline.run(root: Path, config: Config) -> list[FinalVerdict]`
- Orchestrates all of the above in order.
- Returns sorted list: high-risk first, then medium, low, none.
- Caller (CLI) should not call individual modules directly — always go through `pipeline.run`.

### 4. External APIs consumed

#### npm registry — package metadata
- `GET https://registry.npmjs.org/{package}`
  - Response fields used: `dist-tags.latest` (str), `versions` (object keyed by version string), `time` (version→ISO date map)
  - Errors: 404 → package not found; 429 → rate limited (retry with 2s backoff, max 3 tries)

#### npm registry — changelog text
- Strategy: check `repository.url` from package metadata → fetch GitHub releases API for the version range.
- Fallback: `https://registry.npmjs.org/{package}/{version}` `description` field + `CHANGELOG.md` via raw GitHub URL if available.

#### PyPI JSON API
- `GET https://pypi.org/pypi/{package}/json`
  - Response fields used: `info.version` (latest), `releases` (version→file list), `info.project_urls` (for GitHub link)
  - Errors: 404 → package not found

#### GitHub Releases API (changelog source)
- `GET https://api.github.com/repos/{owner}/{repo}/releases`
  - Query params: `per_page=30`
  - Response fields used: `tag_name` (str), `body` (str — markdown changelog), `published_at` (ISO date)
  - Filter: only releases whose `tag_name` semver falls in range `(installed, latest]`
  - Auth: optional `GITHUB_TOKEN` env var for higher rate limits; unauthenticated allows 60 req/hr

#### OSV.dev API — CVE lookup
- `POST https://api.osv.dev/v1/query`
  - Request:
    ```json
    {
      "version": "<installed_version>",
      "package": {
        "name": "<package_name>",
        "ecosystem": "npm" | "PyPI"
      }
    }
    ```
  - Response fields used: `vulns[].id` (CVE id), `vulns[].summary` (str), `vulns[].severity[].score` (str), `vulns[].affected[].ranges` (version ranges), `vulns[].details` (str — used for function extraction)
  - Errors: 400 → bad request; no auth needed; rate limit not documented but treat 429 as retry

#### Anthropic Claude API — verdict via tool_use
- Model: value of `config.model` (default `claude-sonnet-4-5`)
- Method: `client.messages.create` with `tools` param
- Tool definition (must match exactly):
  ```json
  {
    "name": "dependency_verdict",
    "description": "Return a structured verdict for a dependency update given the user's import usage and the changelog.",
    "input_schema": {
      "type": "object",
      "required": ["risk_level", "relevant_changelog_lines", "affected_identifiers", "safe_identifiers", "cve_affects_you", "cve_reason", "summary"],
      "properties": {
        "risk_level":               { "type": "string", "enum": ["none", "low", "medium", "high"] },
        "relevant_changelog_lines": { "type": "array",  "items": { "type": "string" } },
        "affected_identifiers":     { "type": "array",  "items": { "type": "string" } },
        "safe_identifiers":         { "type": "array",  "items": { "type": "string" } },
        "cve_affects_you":          { "type": "boolean" },
        "cve_reason":               { "type": "string" },
        "summary":                  { "type": "string" }
      }
    }
  }
  ```
- System prompt (exact): `"You are a dependency security analyst. Be conservative: when in doubt about impact, rate risk higher rather than lower."`
- User prompt template:
  ```
  Package: {package} {installed} -> {latest}

  Functions I call from this package:
  {identifiers_json}

  Changelog for this version range:
  {changelog_text}

  CVEs found:
  {cve_json}

  Which changelog entries affect the functions I call? What is my actual risk?
  ```
- `tool_choice`: `{"type": "any"}` — force tool use
- `max_tokens`: 1024
- Errors: `anthropic.APIError` → raise `LLMError`; `anthropic.RateLimitError` → retry with 10s backoff, max 2 tries

- [ ] 2. Write `pinpoint/models.py` — define all Pydantic models exactly as specified in the Data Model section; this file must be completed before any other module
- [ ] 3. Write `pinpoint/exceptions.py` — `ScanError`, `FetchError`, `CVEFetchError`, `LLMError` (all subclass `PinPointError(Exception)`)

Write `pinpoint/scanner/base.py` and `pinpoint/scanner/python_scanner.py` — use stdlib `ast`; walk all `.py` files matching include/exclude globs; extract `import x as y`, `from x import a, b, c` → build `ImportMap` per top-level package name; handle `from x.y.z import a` (package = `x`); handle `import *` by adding sentinel `"*"` to identifiers
- [ ] 6. Write `pinpoint/scanner/js_scanner.py` — use tree-sitter; detect language from extension (`.ts`/`.tsx` → typescript grammar, `.js`/`.jsx` → javascript grammar); extract ESM `import { a, b } from 'pkg'`, `import pkg from 'pkg'`, `import * as pkg from 'pkg'`, `require('pkg')`, destructured `const { a } = require('pkg')`; build `ImportMap`
- [ ] 7. Write `pinpoint/scanner/__init__.py` — `scan_project(root: Path, config: Config) -> dict[str, ImportMap]`; detect language if `config.language == "auto"` by file count; merge results from Python and JS scanners

- [ ] 9. Write `pinpoint/fetcher/npm.py` — `NpmFetcher`; fetch npm registry for latest version; fetch GitHub releases for changelog in range `(installed, latest]`; fall back to concatenated npm version descriptions; return `DependencyInfo`

- [ ] 13. Write `pinpoint/llm/claude.py` — `ClaudeEngine(config: Config)`; `get_verdict(import_map, dep, cves) -> ClaudeVerdict`; use tool_use with exact tool definition from API contract; build user prompt from template; parse `tool_use` block from response; validate with Pydantic; raise `LLMError` on failure
- [ ] 14. ## Run instructions (target)

```bash
# Install (once)
pip install pipx
pipx install ./output          # during dev: installs from local source

# Or editable install for development
cd output
pip install -e .

# Required env var
export ANTHROPIC_API_KEY=sk-ant-...

# Optional env var (raises GitHub API rate limit from 60 to 5000 req/hr)
export GITHUB_TOKEN=ghp_...

# Initialize config in your project
pinpoint init /path/to/your/project

# Run scan
pinpoint scan /path/to/your/project

# Run scan, only show medium+ risk, JSON output for CI
pinpoint scan /path/to/your/project --min-risk medium --output json

# Example output line (table mode):
# lodash  4.17.20 -> 4.17.21  debounce, throttle  none  CVE-2021-23337 affects _.template (not used) - safe to skip

# No server to start. No ports. No database. Entirely local + external API calls.
# Typical runtime: 5-30 seconds depending on number of outdated deps and network latency.
```
